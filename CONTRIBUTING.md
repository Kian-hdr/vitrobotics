# Improving the record

Contributions should identify the prototype or test, state the evidence, and distinguish observations from recollections and proposals. Preserve dates and uncertainties. Do not add private documents, personal identifiers, commercial agreements, proprietary code or unlicensed third-party assets.

For CAD, include source ownership, native version, units, manufacturing export format and the related build/test. For flight records, include intervention and abort information as well as successful outcomes.
